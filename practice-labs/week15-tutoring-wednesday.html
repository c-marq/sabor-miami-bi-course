Tutoring Session — Portfolio Assembly Clinic

Wednesday · Immediately after Lab #4 · ~60 minutes · Work with your partner

🤝 Sit with your partner for this entire session. You are building one shared portfolio file and planning a 5-minute presentation together. One machine at a time — one person drives, the other navigates. Swap every 15–20 minutes.
💡 WHAT YOU ARE DOING You and your partner just submitted Lab #4 individually. You both have a polished Sabor Miami model with a hierarchy, Performance Analyzer results, optimized columns, and a dashboard page. Now you combine the best of both into one portfolio file and plan your Monday presentation. This is the last working session before you present.

Minutes 1–10 · Compare files

✅ DO THIS
  1. Both partners open their Lab 4 .pbix files side by side (two laptops, or two windows on one screen).
  2. Compare:
    • Whose dashboard layout is cleaner and easier to read?
    • Whose model has more complete measures?
    • Does one file have a visual or measure the other does not?
  3. Pick one file as the base. This is not a judgment of who did "better" — it is a practical decision about which file gives you the best starting point.

Minutes 10–15 · Create the shared file

✅ DO THIS
  1. Open the chosen base file.
  2. File → Save As → name it Team_LastName1_LastName2_Portfolio.pbix
  3. This is your shared portfolio file from now on. Both partners work from this file.

Minutes 15–40 · Polish together

✅ DO THIS — one person drives, the other navigates Work through these items together:
  • Cherry-pick from the other file. If your partner's file has a measure or visual you like, recreate it in the shared file. Do not copy-paste between .pbix files — just look at it and rebuild.
  • Polish the dashboard. Add a title text box ("Sabor Miami — Business Dashboard" or similar). Align visuals. Make sure the slicer filters all visuals on the page. Consider: does the page tell a clear story?
  • Verify the model. Switch to Model View. Are all relationships active? Is the Date table marked? Is the hierarchy present?
  • Test everything. Click the slicer. Drill down through the hierarchy. Check that every card and chart updates correctly.
🛑 STOP AND CHECK Before moving to presentation planning, run through the Portfolio Checklist in the Portfolio Presentation Guide (available in this Canvas module). Every checkbox should be checked. If anything is missing, fix it now — not over the weekend.

Minutes 40–55 · Plan the presentation

✅ DO THIS Open the Portfolio Presentation Guide (available in this Canvas module). Fill in the planning worksheet together:
  1. Segment 1 — The Data Story (~1.5 min): Assign one partner. Plan which 1–2 data quality issues you will talk about and how you fixed them.
  2. Segment 2 — The Model and Insights (~1.5 min): Assign the other partner. Plan which visuals you will walk through and what they reveal about the business.
  3. Segment 3 — Challenges and Next Steps (~2 min): Both partners speak. Each names one challenge and how they overcame it. Plan what you would do next with more time.

Minutes 55–60 · Save and agree on next steps

✅ DO THIS
  1. Save the shared portfolio file (Ctrl+S).
  2. Decide who keeps the file. Share it with your partner via USB drive, email, OneDrive, or whatever works.
  3. Agree: will you do any more work over the weekend, or is the file ready?
  4. If you plan to work over the weekend, agree on what each person will do and who has the file when.
💜 YOU ARE ALMOST DONE You started this semester without knowing what Power BI was. You are ending it with a clean dataset, a working star schema, DAX measures, an optimized model, and a dashboard you are about to present to your class. Monday is not a test. It is a show-and-tell. You built something real. Now you get to talk about it.

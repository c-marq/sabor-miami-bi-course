Task 1 · Create a Date Hierarchy 8 pts
✅ DO THIS
  1. In Model View, find the Date table.
  2. Right-click Year → Create hierarchy.
  3. Rename the hierarchy to Date Hierarchy.
  4. Drag Quarter onto the hierarchy (Level 2).
  5. Drag Month Name onto the hierarchy (Level 3).
  6. In Report View, create a bar chart using Date Hierarchy on the Y-axis and one of your measures on the X-axis. Drill down to verify Year → Quarter → Month works correctly.
⚠️ COMMON MISTAKE If months appear alphabetically instead of chronologically, set Sort by Column on Month Name → Month Number (Column tools tab in Table View). You set this up in Week 12 — check if it is already working before changing anything.

Task 3 · Remove Unnecessary Columns 8 pts
✅ DO THIS
  1. Save your file and check the file size in File Explorer → Properties.
  2. Identify at least 3 columns that are not used in any relationship, measure, visual, or filter.
  3. For each column: either Hide in report view (right-click in Model View) or Remove in Power Query (open Power Query Editor, right-click column → Remove, then Close & Apply).
  4. Save and check the file size again.
⚠️ COMMON MISTAKE Do not remove: ID columns used in relationships, columns used in measures (like sales[amount]), or Sort By Column targets (like Month Number). When in doubt, Hide instead of Remove — it is safer and still counts for full credit.

Task 4 · Build a Dashboard Page 16 pts
💡 WHY THIS IS THE BIG TASK This is 16 of your 50 points — and it is the most creative task in the lab. You are building a report page that shows the Sabor Miami business at a glance. This dashboard carries directly into your portfolio and your group presentation next Monday. Build it with that in mind.
✅ DO THIS
  1. In Report View, create a new page (click the + icon at the bottom of the canvas, next to the existing page tabs).
  2. Right-click the new page tab and rename it to Dashboard.
  3. Build at least 4 visuals on this page. Requirements:
    • At least 2 different visual types (e.g., bar chart + card, table + pie chart, line chart + slicer)
    • At least 1 slicer (e.g., a truck_name slicer or a Date Hierarchy slicer so users can filter the page)
    • Use your existing measures — Total Sales, Total Tips, Average Ticket, Transaction Count, Tip Percentage, La Havana Express Sales, or any others you wrote in Lab #3
  4. Arrange the visuals so the page looks intentional, not random. Align edges. Leave some white space. Give the page a title using a Text Box (Insert tab → Text Box).
💡 DASHBOARD DESIGN TIPS
  • Top of the page: Big numbers (Card visuals) that give the high-level picture — total revenue, total transactions, average ticket.
  • Middle of the page: Charts that show comparisons — revenue by truck, revenue by month, tips by payment method.
  • Side or top: Slicers for filtering — let the user pick a truck, a time period, or a category.
  • Bottom or side: A detail table for users who want to see the numbers behind the charts.
You do not have to follow this layout. It is one common pattern. Build something that tells a story about Sabor Miami's business.
🛑 STOP AND CHECK Before taking your screenshot, test the slicer. Click on a truck name (or a date range) and confirm that all the other visuals on the page update. If a visual does not respond to the slicer, check that the tables involved have active relationships in Model View.

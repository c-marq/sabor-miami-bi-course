Task 4: Tip Percentage 5 pts

What we want to ask: "What percentage of total sales came from tips?"

This measure is more complex — it nests two SUM functions inside DIVIDE:

Tip Percentage = DIVIDE(SUM(sales[tip]), SUM(sales[amount]))
💡 WHY DIVIDE INSTEAD OF ÷?

You could write SUM(sales[tip]) / SUM(sales[amount]) — and it would work most of the time. But if the denominator (total amount) is ever zero (for example, if a slicer filters to a truck with no sales), the / operator crashes with an error. DIVIDE handles this gracefully — it returns blank instead of an error. Always use DIVIDE for safe division.

✅ DO THIS
  1. Click the sales table → Home tab → New Measure.
  2. Type Tip Percentage = DIVIDE(SUM(sales[tip]), SUM(sales[amount])) and press Enter.
  3. Create a Card visual and drag Tip Percentage into it.
  4. Format as percentage: Click the Tip Percentage measure name in the Data pane. On the ribbon, find the Measure tools tab → change the format dropdown from General to Percentage.
⚠️ COMMON MISTAKE

Tip Percentage shows a huge number like 1,500%. — Check that you put sales[tip] as the first argument (numerator) and sales[amount] as the second (denominator). If they are reversed, you are dividing total sales by total tips, which gives an inflated result. Tips as a percentage of sales should be somewhere between 5% and 25%.

Task 5: Transaction Count 5 pts

What we want to ask: "How many sales transactions are in the dataset?"

Transaction Count = COUNTROWS(sales)

Notice: COUNTROWS takes a table name — just sales, no column in brackets. It counts rows, not values in a column.

✅ DO THIS
  1. Click the sales table → Home tab → New Measure.
  2. Type Transaction Count = COUNTROWS(sales) and press Enter.
  3. Create a Card visual and drag Transaction Count into it.

Task 6: Unique Items Sold 5 pts

What we want to ask: "How many different menu items were sold — not how many total items, but how many unique items?"

Unique Items Sold = DISTINCTCOUNT(sales[menu_item_id])
💡 DISTINCTCOUNT vs. COUNTROWS

Think of it as counting heads at a family reunion. COUNTROWS tells you how many plates were served (including people who came back for seconds). DISTINCTCOUNT tells you how many unique people showed up. If Sabor Miami has 15 menu items but only 12 were sold, DISTINCTCOUNT returns 12.

✅ DO THIS
  1. Click the sales table → Home tab → New Measure.
  2. Type Unique Items Sold = DISTINCTCOUNT(sales[menu_item_id]) and press Enter.
  3. Create a Card visual and drag Unique Items Sold into it.

Phase 3 of 4 — CALCULATE and Your Choice

Write Measures 7–8

Task 7: La Havana Express Sales 8 pts

What we want to ask: "What is the total sales for La Havana Express — regardless of any other filters on the page?"

Every measure you have written so far respects filter context — when you click a slicer, the numbers change. But sometimes you need to force a specific filter. CALCULATE lets you do that.

La Havana Express Sales = CALCULATE(SUM(sales[amount]), trucks[truck_name] = "La Havana Express")

Let's break this down:

La Havana Express Sales = CALCULATE( ← take this calculation... SUM(sales[amount]), ← (the sum of all sale amounts) trucks[truck_name] = "La Havana Express" ← ...but ONLY for this truck )
💡 HOW CALCULATE WORKS

CALCULATE takes two things: (1) the calculation you want to run, and (2) a filter to apply. It overrides the filter context from the visual. So even if a slicer is set to "Caribbean Cruiser," this measure still shows La Havana Express's sales — because CALCULATE forces its own filter.

Notice that the filter references trucks[truck_name] — a column in the trucks table, not the sales table. This works because the trucks table is connected to sales through a relationship. The filter flows through the relationship.

✅ DO THIS
  1. Click the sales table → Home tab → New Measure.
  2. Type the following and press Enter:
    La Havana Express Sales = CALCULATE(SUM(sales[amount]), trucks[truck_name] = "La Havana Express")
  3. Create a Card visual and drag La Havana Express Sales into it.
🛑 STOP AND CHECK

Compare your La Havana Express Sales Card to your Total Sales Card. La Havana Express Sales should be smaller — it only includes one truck's transactions. If both numbers are the same, check that you typed the truck name correctly inside the quotes: "La Havana Express" — spelling, capitalization, and spaces must match exactly.

⚠️ COMMON MISTAKE

The measure returns blank or zero. — The truck name in quotes must match exactly what is in the data. Check the trucks table in Table View for the exact spelling. Common issues: extra space, wrong capitalization, or a different truck name than expected.

English Question Possible DAX
